# Employee Attrition Prediction System

## 📌 Project Overview

The Employee Attrition Prediction System is a Machine Learning project developed to predict whether an employee is likely to leave an organization based on various HR-related attributes. The project follows the complete Machine Learning workflow, including data collection, preprocessing, exploratory data analysis (EDA), model training, evaluation, and result analysis.

---

# 🎯 Problem Statement

Employee attrition is one of the major challenges faced by organizations. This project predicts employee attrition using Machine Learning algorithms based on employee-related features such as Age, Education, Job Role, Monthly Income, Overtime, Work-Life Balance, and Total Working Years.

---

# 📂 Dataset Information

**Dataset Name:** IBM HR Analytics Employee Attrition Dataset

**Source:** Kaggle

- Total Records: **1470**
- Total Features: **35**
- Target Variable: **Attrition**
- Type: Classification Dataset

# 📋 Model Performance

|--------|----------|
| Logistic Regression | **87.41%** |
| Decision Tree | **76.19%** |
| Random Forest | **87.41%** |
